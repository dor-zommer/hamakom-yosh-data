# נתוני מעקב התכנון ביו״ש — המקום הכי חם בגיהנום

פלט מכונה של פרויקט מעקב ההתנחלויות. הקבצים כאן מיוצרים אוטומטית מ-`osint.db`
ומזינים את [עמוד הדאטה](https://www.ha-makom.co.il/ha-makom-data-hub/).
**אין לערוך אותם ידנית** — כל שינוי יידרס בייצוא הבא.

| קובץ | תוכן |
|---|---|
| `plans-map.json` | כל תוכנית בנייה שמיקומה ידוע: מיקום, סטטוס, מגזר, יח״ד, שטח, קישור למאב״ת |
| `plans.geojson` | תוכניות 2026 שמיקומן ידוע ולא נדחו, כ-GeoJSON |
| `settlements.geojson` | אגרגציה לפי יישוב |
| `stats.json` | מספרי הליבה: סה״כ, שיעורי אישור לפי מגזר, יח״ד בתוכניות מול מאושרות, פילוח לפי שנה, ייעודי קרקע, והצלבה עם שטח C / אדמת מדינה / שטחי אש |
| `week.json` | מה נכנס למאגר לאחרונה |

## מקור ומגבלות

הנתונים נאספים ממאגר התכנון של המנהל האזרחי (מאב״ת). לפני כל שימוש עיתונאי:

- **תמיד לאמת מול `pl_url`** — הרשומה במאגר היא ליד, לא ממצא מאומת.
- **`sector` הוא סיווג אוטומטי שלנו**, לא נתון של מאב״ת. הוא עלול לטעות במקרי קצה.
- **`units` משקף את מאב״ת כולל טעויותיו.** ידועים מקרים שבהם שטח בנייה במ״ר קודד
  כיחידות דיור. ייצוא זה חוסם רשומות עם צפיפות בלתי אפשרית, אך אין להסתמך על
  מספר יח״ד ספציפי בלי לפתוח את מסמך התוכנית.
- **"הופקד" אינו "אושר" ואינו "נבנה".** `station_desc` הוא השלב בהליך.

## רישיון

הנתונים הגולמיים הם מידע ציבורי של המנהל האזרחי. האיסוף, הסיווג והנגזרות הם של
"המקום הכי חם בגיהנום". שימוש מותר עם ייחוס.
